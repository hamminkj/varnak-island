## Where-questions

Ti hama ta-esh-ha? is from the document (section 26.2). The answers An tekama na-esh-da / An morama na-esh-da / An senama na-esh-da are composed: independent pronoun an, locative -ma, 1S prefix na-, esh, -da.

## Counting piles

Number words (yan, vel, mur, kes, pan) are from section 31.1. The game shows only the number and noun, for example Mur sek (three stones), following the doc's mur sair (three people).

## Word workshop

Roots are single nouns from the vocabulary lists. Endings are the case and number suffixes from sections 19.2 and 19.3: -du, -ir, -li, -ma, -ni, -ru, -se, -su, -ta, -ven. Forms are plain concatenation (root + ending), as in tekama, tabma, korma, morata and kerli. Decisions I made:

- Consonant-final roots take the ending directly (for example domma, tabke), following senma and tabma. The e-insertion rule is only described for difficult clusters, and none of these roots end in a cluster.
- tari + -ir is not offered, because tari + ir would be written tariir, which reads as a long vowel. Tell me the intended spelling and I will add it.

Workshop nouns: dom (house), fal (flower), gira (bridge), gor (dog), guro (fruit), kor (container), mar (horse), mara (field), mora (river), mun (door), murak (tree), par (bird), puka (book), sena (boat), tab (table), tari (fish), teka (village), wak (water).
